# tutor-tracker

Учёт учеников для репетитора: список учеников, поиск, сохранение данных между запусками.
Учебный проект на Go, который я развиваю до backend-сервиса.

## Возможности
- Добавление учеников с автоматической выдачей ID
- Поиск ученика по ID
- Сохранение и загрузка данных в JSON-файл
- Автотесты

## Запуск
```bash
go run .
```

## Тесты
```bash
go test -v ./...
```

## Структура
- `main.go` — точка входа программы
- `internal/store` — хранилище учеников: добавление, поиск, сохранение в JSON

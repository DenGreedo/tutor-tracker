# tutor-tracker

Учёт учеников для репетитора: список учеников, поиск, сохранение данных между запусками.
Учебный проект на Go, который я развиваю до backend-сервиса.

## Возможности
- REST API для учёта учеников
- Сохранение данных в JSON-файл между запусками
- Валидация входящих данных
- Потокобезопасное хранилище (sync.Mutex)
- Тесты хранилища и HTTP-обработчиков (httptest, табличные тесты)

## API

| Метод | Путь | Описание | Успешный ответ |
|---|---|---|---|
| GET | `/health` | проверка, что сервис работает | 200 |
| GET | `/students` | список учеников | 200 |
| GET | `/students/{id}` | один ученик | 200, 404 |
| POST | `/students` | добавить ученика | 201, 400 |
| DELETE | `/students/{id}` | удалить ученика | 204, 404 |

Пример запроса на добавление ученика - в `examples/create_student.json`:
```bash
curl -X POST http://localhost:8080/students \
  -H "Content-Type: application/json" \
  --data-binary @examples/create_student.json
```

## Структура
- `main.go` - точка входа: загрузка данных и запуск сервера
- `internal/store` - хранилище учеников: добавление, поиск, удаление, сохранение в JSON
- `internal/httpapi` - HTTP-слой: маршруты, обработчики, валидация
